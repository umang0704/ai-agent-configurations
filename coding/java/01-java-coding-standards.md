# Java code standards

## packages
- package naming should be in small letters
- package should have '-' as delimiters between names
- packages should identify features and components

## class
- class names should start with CAPS
- class names should follow PascalCase
- class names should be a noun

## variables

- class variable should have meaningful name
- class variables should start with small letters
- class variables should be in camelCase
- class variable access modifiers should be defined meaningfullt

## method
- class method name should be in present perfect tense
- class methods should use a verb-noun pair in camelCase
- class methods that return true or false with is, has, or can
